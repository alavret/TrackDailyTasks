# Исключения из уведомлений о будущем удалении заблокированных пользователей
# Для этих пользователей не будут отправляться уведомления об удалении,
# и они не будут учитываться в отчётах о приближающемся удалении.
#
# Формат файла: каждая строка содержит один идентификатор пользователя.
# Можно использовать:
#   - email (например, user@example.com)
#   - nickname/логин (например, user123)
#   - uid (например, 1130000000000123)
#
# Строки, начинающиеся с # - комментарии (игнорируются).
# Пустые строки игнорируются.
#
# Пример:
# system.user@company.com
# service_account
# 1130000000000999

someusers@domain.ru
